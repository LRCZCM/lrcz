# 界面设计规范

状态：第一版（2026-11-11），随主页一起确定。CSS 与组件写法见 [开发规范的组件与样式](DEVELOPMENT.md#组件与样式)。

## 基础

- 风格：像苹果官网那样简洁。大标题、大留白、居中排版，一屏只讲一件事；内容靠文字层级与产品截图表达，不堆装饰。
- 组件外观与动效以 [HeroUI v3](https://heroui.com/) 为准，直接用其组件和默认主题（强调色为默认的蓝色）；定制时只改主题变量，不逐个组件覆盖样式。
- 品牌标志：两块等轴方块，橙色“太阳”方块正落到深蓝方块上，寓意“来日创造”（`src/pages/home/BrandMark.tsx`，造型取自 LCML 图标）。标志放在“来日创造”文字前，高度约为字号的 1.15 倍。
- 文字克制：页面只放必要信息（品牌名、LRCZ、联系邮箱、产品入口、版权、备案号），不写介绍性长文案。
- 产品入口：邮箱按钮左边的“产品”主按钮（HeroUI `Button` 加 `Dropdown`），下拉面板每行一个产品：40px 圆角图标、名称与一行短说明，点击进入产品页（`src/pages/home/ProductMenu.tsx`）。以后的产品都加在这个面板里，首页布局不变。点击、触屏与键盘可打开；桌面端鼠标悬停也会打开，离开 200ms 后关闭。
- 视觉居中：首页主体整块底部多留 8vh，使其略高于几何中心。
- 品牌色只出现在标志上；主要操作（产品）用 HeroUI 主按钮，次要操作（邮箱）用中性灰的 `tertiary`。
- 字体用系统字体：苹方、SF、Segoe UI、微软雅黑（见 `src/styles/index.css`）。
- 颜色模式跟随系统的浅色 / 深色设置，暂不提供手动切换；颜色只用主题语义类。
- 图标统一用 Lucide，同一区域内图标尺寸一致。

## LCML 产品页

- 结构（从上到下）：吸顶顶栏（“来日创造”返回首页、LCML、功能、更新日志、反馈、下载）→ 首屏（图标放在“LCML”左侧、与文字同高，一句话，下载主按钮与旁边的 GitHub 次按钮，版本号）→ 启动器演示 → 功能卡片 → 更新日志 → 结尾下载与反馈 → 页脚。
- 启动器演示是对 LCML 界面的网页复原：按启动器默认窗口 1100×660 布局再整体缩放，颜色、字号、圆角、文案照搬 LCML（`demo/tokens.ts` 中的配色取自 LCML 的 `tokens.css` 与外观预设），所以演示内部不用本站主题色，也不跟随本站深浅色。模组、服务器等第三方项目的图标不用其标志，用色块加首字母代替。
- 演示下方用小字说明：动画是网页模拟的界面示意，并非软件实际画面，部分图标与细节会有出入；并注明 LCML 基于 JavaFX 开发。
- 演示自动循环播放，光标模拟点击；下方章节只写标题（不加说明文字），显示当前进度，点击任一章节从该章开始。窄屏时章节横向滑动，当前章节自动滚到中间。
- 更新日志加载时显示骨架，失败时提示并给“重试”；每条改动按类型显示标签：增加为绿、更新为蓝、修复为橙、移除为红（HeroUI `Chip` 的 soft 样式）。默认显示最近 3 个版本。

## LCML 使用手册

- 参照常见文档站（Apple 开发者文档、VitePress、GitBook）：吸顶顶栏（“来日创造”、LCML、“使用手册”，右侧搜索与下载）下分三栏，左为分组章节导航，中为正文（最宽 760px），右为“本页目录”并随滚动高亮当前小节。屏宽不足 1280px 时隐藏右栏，手机端左栏改为点菜单按钮打开的抽屉，换页后自动关闭。
- 手册首页：README 的标题与引言，蓝色“快速上手”大入口，再按分组排列章节卡片（编号、标题、本章各小节名），最后是 README 其余内容。
- 正文排版：一级标题 30–40px，引言放大变灰；二级标题上方有分隔线；顶层数字列表画成带圆形序号的步骤；每项都是“**名词**：解释”的列表画成两栏术语表；表格用 HeroUI `Table`；截图圆角、细边框、轻阴影，按“整窗截图（1280 宽）占满正文”的同一比例缩放，点击用弹窗看大图；站内链接直接跳到对应章节的小节，外链新窗口打开并带 ↗。
- 章节页顶部是“使用手册 › 分组”，底部是上一章 / 下一章与“在 Issues 提问”。
- 搜索：Ctrl K 或 `/` 打开弹窗，按小节匹配标题与正文，标题命中排前，按章节分组，关键词高亮，方向键选择、回车跳转。

## 交互底线

- 所有耗时操作（请求、提交、导出）有加载态，结束后明确告知成功或失败，不静默结束。
- 后到的数据不突然插入：能预知形状的区块先显示骨架，数据到达后原地淡入；切换时原地变骨架而不是先清空。
- 状态切换不改变布局尺寸，避免页面跳动。
- 左右留白、边距对称；文字容器与图标、按钮在行内竖直居中。
- 描边与阴影不被滚动区或裁剪容器切掉。
- 文案通俗、简短；标题能看懂就不加副标题。
- 有风险的操作（删除、覆盖）才需要确认；其他修改尽量即时生效。

## 动效

- 组件交互（悬停、按下、展开、弹层出入）用 HeroUI 自带动效，不另做。
- 组件内的入场：淡入加 4–8px 位移，200–300ms，`easeOut`；退场比入场更快。
- 主页入场：标志底座淡入，太阳方块从上方旋转落下并停在倾斜 10° 的位置（1.4s）；随后文字、LRCZ、按钮行依次上移 16px 淡入，间隔 150ms，曲线 `[0.22, 1, 0.36, 1]`。
- 高度变化只在内容变化处做一次过渡，外层跟随，不多层追赶。
- 遵守系统“减少动效”设置：减少时取消位移，只保留或取消淡入（Motion 用 `useReducedMotion` 或 `MotionConfig reducedMotion="user"`）。

## 响应式

以桌面端为主，同时保证 360px 宽的手机屏幕可用、无横向滚动。标题字号随屏宽在 48–120px 之间缩放。
