- 用户提供 SSH 后，服务器上的安装、配置、重启、排查由我直接做并汇报结果，不把命令丢给用户执行；只有必须用户本人登录的网页操作（GitHub 仓库设置、Jenkins 凭据与权限页等）才留给用户，且尽量压到一两步。
- 改服务器文件前先备份（`<文件>.bak-<日期>`），改完立刻实测并报告备份位置；有语法检查的先检查再重载（如 `openresty -t`）。
- 服务器密码、私钥不写进任何文件、文档或提交；私钥能在服务器上生成就不经过聊天。

**Why:** 用户搭 Jenkins 时给了 SSH 并说“你帮我操作”，嫌多步网页配置“太麻烦”（2026-11-17）。

**How to apply:** 服务器事实与现状记在 LRCZ 的 DECISIONS“部署”“插件分发（Jenkins）”。相关：[[verify-before-recommend]]。
