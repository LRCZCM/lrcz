metadata:
  type: feedback
---

1. 需要用户拍板的点集中问一次，确认后一次性开发完毕，不分多轮请示。
2. 做完主动列出“怎么测试”的具体步骤。
3. 用户说“测过了 / 没问题” + “更新文档，提交” → 直接同步 NOW/DECISIONS 等文档并提交。用户没说测过就不提交。

**Why:** 沿用自 LCML 项目的固定节奏。

**How to apply:** 用户只确认部分测过时，只把已测部分写成已验证。相关：[[now-doc-cadence]]。
