每完成一步，把简要记录（做了什么、决定链接、验证结果、未验证范围）追加到 NOW 末尾“近期记录”，编号接续。用户说“整理 NOW”时，并入“进度”总结、更新“待人工验证”，原文存为 `docs/archive/NOW-<日期>.md`。

**Why:** LCML 的 NOW 曾因流水账涨到 126KB，用户要求改为定期手动整理。

**How to apply:** 不自行发起整理；不把细节铺进“进度”总结。
